 NAME
-------------------------------------------------------------------------------

 Channel Search+ for YouTube

 Not "YouTube Channel Search+". Google's branding rules do not allow a product
 name that begins with YouTube. The "X for YouTube" form is the accepted one.


-------------------------------------------------------------------------------
 SHORT DESCRIPTION            132 char limit
-------------------------------------------------------------------------------

 YouTube's channel search only matches text. This searches the whole back
 catalogue by length, views, date and what you've watched.

 (129 characters. Must match the manifest description exactly.)


-------------------------------------------------------------------------------
 DETAILED DESCRIPTION
-------------------------------------------------------------------------------

YouTube's in-channel search only matches words in titles. You cannot ask it for
videos under twenty minutes, or the ones you started and never finished, or a
big channel's best work. This adds all of that.

Open any channel's Videos tab and press the Search+ button. The extension reads
the channel's entire upload history, then replaces the grid with one you can
actually query. Free, with no paid tier and nothing held back.

SEARCH
- Length, view count, upload date, and keyword, combined freely
- Watch state: hide what you have finished, or find what you abandoned
- Free time: pick the minutes you have, see only what fits
- Start here: a spread of a channel's best work for when you arrive cold
- Sort by views per day, which surfaces breakouts rather than just old uploads

INSIGHTS
- Where a channel's sweet spot is, stated plainly, with the charts underneath
- Uploads per year, and whether the typical video is growing or shrinking
- View and length distributions, clickable to filter the grid
- Which words and title formats lift median views, and by how much
- Compare any two channels side by side
- Keep a watchlist and see what is outperforming across all of them

Most in-page filter tools only touch the video cards already loaded on screen.
This reads the channel's complete catalogue first, so every sort, statistic and
chart covers all of it rather than just what you scrolled past.

Everything runs in your browser. No account, no API key, no server, and nothing
is ever sent anywhere. Full source is published.

Not affiliated with YouTube or Google.

-------------------------------------------------------------------------------
 PERMISSION JUSTIFICATIONS      the dashboard asks for each one
-------------------------------------------------------------------------------

 storage
   Stores the user's own settings, such as which sort the panel opens on and
   how deep to read a channel, so they persist between sessions. No browsing
   data is placed in sync storage.

 Host permission for www.youtube.com
   The extension's entire function is to read a YouTube channel's public video
   listings and render a filtered view of them onto that page. It requests the
   same listing endpoints the site itself uses, and it draws its interface into
   the channel page. It runs on no other site.

 Remote code
   None. All code is contained in the package. No scripts are fetched or
   evaluated at runtime.

 Data usage disclosures, tick these
   [x] Website content ....... video titles, lengths, view counts, upload dates
                               and the user's own watch progress, all read from
                               the page and kept on the device
   [ ] Personally identifiable information
   [ ] Health, financial, authentication, personal communications, location,
       user activity beyond the above, web history

   And certify:
   [x] Not being sold to third parties
   [x] Not used or transferred for purposes unrelated to the single purpose
   [x] Not used or transferred to determine creditworthiness


-------------------------------------------------------------------------------
 SINGLE PURPOSE STATEMENT
-------------------------------------------------------------------------------

 Searching and filtering the videos of a YouTube channel.

 Every feature serves that: the filters narrow a channel's catalogue, the charts
 describe it, and the comparison view sets one channel's catalogue against
 another. Keep the framing tight. Review objects to extensions that read as a
 bundle of unrelated tools.
