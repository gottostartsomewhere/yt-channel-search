===============================================================================
 YOUTUBE CHANNEL SEARCH+   MANUAL TEST CHECKLIST
===============================================================================

 No automated tests exist, so run this before tagging a release or merging
 anything that touches the panel.

 SETUP
   - Sign in to YouTube. Every watch feature reads as empty if you are not.
   - Use a channel with 300+ videos, a mix of Shorts and long uploads, and
     some you have actually watched. @mkbhd, @veritasium, @LinusTechTips.
   - Run: node build.js
   - Load dist/chrome, NOT the repo root. The manifest points at src/ now.


-------------------------------------------------------------------------------
 1. SMOKE          the first two decide whether the rest is worth running
-------------------------------------------------------------------------------

 [ ] Panel opens on a channel Videos tab from the Search+ button
 [ ] Console is clean. A ReferenceError here means the content scripts loaded
     out of order. Check the js array in manifest.json
 [ ] Catalog loads, count climbs, ends near the channel's real video count
 [ ] Alt+Y opens and closes the panel
 [ ] Toolbar icon opens the popup
 [ ] Restore YouTube brings the native grid back untouched
 [ ] Switching channel and reopening loads the new one, not the previous


-------------------------------------------------------------------------------
 2. POPUP
-------------------------------------------------------------------------------

 [ ] Open on this channel opens the panel and closes the popup
 [ ] On a non-YouTube tab the button is disabled with an explanation
 [ ] On a stale YouTube tab it says to reload, rather than failing silently
 [ ] Every setting persists across close and reopen
 [ ] Reset restores defaults
 [ ] Change shortcut opens the browser shortcut page

 Settings must actually reach the panel:

 [ ] Opening sort .......... panel opens already sorted that way
 [ ] Hide finished ......... finished videos absent on open
 [ ] Open automatically .... panel opens without clicking
 [ ] Video limit ........... set 60, refresh, catalog stops near 60
 [ ] Finished at ........... set 50, videos past halfway count as finished
 [ ] Outlier threshold ..... raising it leaves fewer badges


-------------------------------------------------------------------------------
 3. FILTERS        each should narrow the count instantly, no reload
-------------------------------------------------------------------------------

 [ ] Keyword matches titles, case-insensitive

 [ ] Length    Any / under 1m / 1-4m / 4-20m / 20-60m / over 60m
 [ ] Views     Any / under 10K / 10-100K / 100K-1M / 1-10M / over 10M
 [ ] Uploaded  Any / past week / month / 3 months / year / over a year
 [ ] Watched   Any / not started / not finished / still watching / finished
 [ ] Fits in   10 shows nothing longer than ten minutes

 [ ] Filters combine
 [ ] FLAGSHIP: Fits in 25 + Watched not started returns a sensible short list
 [ ] Clear appears only when something is active, and resets everything
 [ ] Count turns accent-coloured while filtered
 [ ] A filter matching nothing shows the empty state, not a blank pane


-------------------------------------------------------------------------------
 4. SORTS
-------------------------------------------------------------------------------

 [ ] Newest
 [ ] Oldest is the exact reverse of Newest
 [ ] Start here spreads across years, not all from one period
 [ ] Most views
 [ ] Fewest views
 [ ] Longest
 [ ] Shortest
 [ ] Views per day DIFFERS from Most views. If identical the age
     normalisation is broken and the feature is decorative
 [ ] Trending (measured) needs two refreshes apart, see section 8
 [ ] Hidden gems surfaces smaller videos punching above their weight
 [ ] Title A to Z


-------------------------------------------------------------------------------
 5. CARDS
-------------------------------------------------------------------------------

 [ ] Thumbnail, title, views, age all present and correct
 [ ] Duration badge matches the video
 [ ] Clicking a card opens that video
 [ ] Partly watched videos show a resume bar at the right position
 [ ] Finished videos are dimmed but still present
 [ ] Outlier badges show a multiplier
 [ ] New uploads since last refresh carry a NEW badge
 [ ] Over 600 results shows the truncation note


-------------------------------------------------------------------------------
 6. EXPORTS
-------------------------------------------------------------------------------

 [ ] CSV downloads and opens in a spreadsheet
 [ ] CSV reflects current filters, not the whole catalogue
 [ ] Titles containing commas and quotes survive the CSV round trip
 [ ] JSON downloads and parses


-------------------------------------------------------------------------------
 7. TABS
-------------------------------------------------------------------------------

 ANALYTICS
 [ ] Uploads per year renders
 [ ] Median views by year renders
 [ ] Views and length distributions render
 [ ] Median views by video length draws a line with a labelled peak
 [ ] Clicking a distribution bar filters the grid and switches to it
 [ ] Compare accepts @handle, bare handle, and full URL
 [ ] Compare bolds the winning value per row
 [ ] A nonsense channel name reports a parse failure, does not hang

 TITLES
 [ ] Two columns, filling the width
 [ ] Words that lift performance shows real words, not filler like "gets"
 [ ] No mangled contractions such as "youre"
 [ ] Title format percentages look plausible
 [ ] Median views by title length skips empty bands rather than drawing gaps

 SERIES
 [ ] Groups recognisable series, for example numbered parts and episodes
 [ ] A channel with no series shows the empty state

 NICHE
 [ ] Track channel adds a chip
 [ ] Chip remove button works and survives a reopen
 [ ] Refresh all reports progress per channel
 [ ] What is working right now lists videos with a multiplier
 [ ] Content gaps lists topics absent from the current channel
 [ ] An unreachable channel is counted in the status, not swallowed
 [ ] Nothing outperforming shows the empty state


-------------------------------------------------------------------------------
 8. PERSISTENCE       needs two sessions with a real gap, save for last
-------------------------------------------------------------------------------

 [ ] Reopening a channel loads instantly from cache and says so
 [ ] Refresh re-reads and updates the timestamp
 [ ] A pre-watch-state cache asks for a refresh instead of reporting
     everything as unwatched
 [ ] After a second refresh hours later, cards show gains like "+12K in 6h"
 [ ] Trending (measured) then orders by those gains
 [ ] Niche status flips from baseline to live once channels have 2 snapshots
 [ ] Watchlist survives a browser restart


-------------------------------------------------------------------------------
 9. EDGE CASES
-------------------------------------------------------------------------------

 [ ] A channel with no Videos tab fails with a message, not a stuck spinner
 [ ] A channel with a handful of videos still renders every pane
 [ ] Signed out: watch filters are inert, nothing crashes
 [ ] Narrow window: the control bar wraps without overlapping
 [ ] Light theme: text stays legible
 [ ] Reopening the panel repeatedly does not stack duplicates


-------------------------------------------------------------------------------
 10. FIREFOX          load dist/firefox via about:debugging
-------------------------------------------------------------------------------

 [ ] Panel opens. If not, grant the YouTube host permission from the addons
     panel. Firefox MV3 treats host permissions as opt-in
 [ ] Popup renders and settings persist
 [ ] Alt+Y works
 [ ] Change shortcut opens about:addons

 MOST LIKELY TO FAIL
   - Section 1, load order. The module split is unverified at runtime.
   - Section 7 Titles. Stopword fix was never seen running.
   - Section 10 Firefox. Entirely unverified, no Firefox available here.
